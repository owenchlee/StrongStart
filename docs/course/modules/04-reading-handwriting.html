04

Reading handwriting

Photo → Cloudinary → Gemini → review queue: how a paper form becomes a dashboard row without anyone typing it in

Three ways feedback arrives

A facilitator photographs a stack of paper forms on their phone and taps Upload. Twenty seconds later the ratings are on the staff dashboard, the Spanish comments have an English translation, and two forms are waiting for a human because the handwriting was unclear.

Think of a pharmacist reading a prescription. Doctors' handwriting is famously bad, yet the pharmacist makes the slip legible, copies it into a fixed form, and passes anything doubtful to a second person before dispensing. Nothing is guessed, and that is exactly how this module's code behaves.

Trust the bytes, not the name

Module 3 showed that the upload URL carries the program token and sits on the public allow-list, so the server checks the token before anything else. Then it checks the file itself.

A filename like form.jpg is just a label the phone or the browser chose. The server ignores it and reads the first 12 bytes of the file instead: the magic number that every real image type begins with.

src/routes/feedback.js, lines 42–46, inside sniffImage; b holds the first 12 bytes of the file
CODE 

    if (b[0] === 0xff && b[1] === 0xd8 && b[2] === 0xff) return 'image/jpeg';
    if (b.subarray(0, 8).equals(Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]))) return 'image/png';
    if (b.subarray(0, 4).toString('latin1') === 'GIF8') return 'image/gif';
    if (b.subarray(0, 4).toString('latin1') === 'RIFF' && b.subarray(8, 12).toString('latin1') === 'WEBP') return 'image/webp';
    return null;
PLAIN ENGLISH

If the first three bytes are the hex values FF D8 FF, this is a JPEG. Say so and stop.

If the first eight bytes equal the fixed PNG signature (compared as a Buffer), this is a PNG.

If the first four bytes spell GIF8 when read as plain latin1 letters, this is a GIF.

If bytes 0 to 4 spell RIFF and bytes 8 to 12 spell WEBP, this is a WebP image.

Otherwise answer null: not an image we accept. The caller deletes the file and tells the uploader it is not a valid image.

💡
Key Insight

Browsers and attackers both lie about file types. Reading the first bytes (the magic number) is the standard defence, and the returned MIME type also decides the proper extension the file is saved under.

Make it legible first

Before reading a scrawled prescription, the pharmacist flattens the slip and holds it under a bright lamp. That is the job of sharp and Cloudinary here: sharp finds the angle at which rows of ink line up best, and Cloudinary rotates by that angle.

The original photo is always kept. Cloudinary derives a second copy from it using a transformation chain, and only that copy is shown to Gemini.

PLAIN ENGLISH

Define a constant called readable: an arrow function that takes a tilt (default 0) and returns a list of edits.

First, turn the photo the right way up using the EXIF data the phone stored.

Only if sharp found a tilt, add a rotation step (the spread operator inserts it or inserts nothing). Fill the corners with white.

Cap the image at 2000 by 2000 pixels. Shrink if bigger, never stretch if smaller.

Drop the colour: grayscale makes ink stand out from paper.

Fix the exposure automatically, then push brightness up a further notch for dim halls.

Boost contrast so faint pencil reads as dark.

Apply an unsharp mask to crisp up the pen strokes.

Finally, compress sensibly and deliver as a JPEG.

End of the list.

Read it into a fixed form, and never take orders from the page

The pharmacist copies the prescription into a fixed form: drug, dose, frequency. If the slip also says please give me extra, that is a note to record, not an order to follow.

Gemini gets the same two rules. A system prompt declares everything on the page to be data, and a schema forces the answer into a fixed JSON shape. In OCR terms, Gemini is doing the reading and the form-filling in one pass.

⚠️
Prompt injection

Prompt injection is text inside the data pretending to be instructions. The defence here is to say so in the system prompt, wrap the data in markers, and validate the JSON shape afterwards.

When to ask a human

When the pharmacist cannot read a dose, they do not guess: they ask a colleague. Here that colleague is the review queue, and three fallbacks make sure a form is never silently lost on the way there.

☁

No Cloudinary

Keys missing or quota hit? The file stays on the server's disk with its sniffed extension, and Gemini reads the local path. Only hosting is lost.

Enhanced copy fails

If reading the cleaned-up image throws an error, the server retries with the untouched original. Two chances to read before giving up.

PLAIN ENGLISH

Start with no transcript (t) and no error.

Outer try: everything inside may fail without crashing the upload.

Inner try: ask Gemini to read the enhanced image (aiSource).

If that fails, think before retrying. A quota or rate-limit error would fail the same way again and only burn more of the allowance.

So give up straight away if there is no original photo to fall back to, or if the error message contains 429 or RESOURCE_EXHAUSTED (Gemini saying its free allowance or rate limit is used up).

Otherwise, log the problem and try again with the original, untouched photo.

If we gave up or both attempts failed, the outer catch takes over.

Record a friendly error message that the dashboard can show next to the form.

Check once more whether this was a quota problem.

Log it in plain words if so (Gemini quota or rate limit reached, form saved for staff review), otherwise log the technical detail. Either way the form is still saved and flagged.

End of the error handling.

The review rule: flag the row if there is no transcript, or confidence is low, or no rating was found, or the text contains [illegible] anywhere (checked with a regex).

Just before this rule runs, normalizeFeedback clamps every field, so even a strange answer from Gemini cannot put bad data in the table. The flag itself is a single true or false column, needs_review, which staff flip back to false once they have checked the row.
